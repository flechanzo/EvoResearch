# Milestone 4D: end-to-end lifecycle audit

M4D composes M4A gap discovery and generation, M4B criticism-driven mutation, and M4C externally supplied evaluation and Pareto selection into one deterministic fixture. It does not score hypotheses, call a model, run an experiment, or alter the previous milestone contracts.

The lifecycle output preserves the complete population and genealogy, records the validated gap and provenance path, retains mutation edges and criticism/evidence links, stores the complete evaluation vectors, and explains each selected frontier hypothesis. The report is a deterministic projection over those records and contains originating problem nodes, evidence IDs, mutation reasons, criticisms, evaluation dimensions, and Pareto rationale.

The final checkpoint hashes the full lifecycle projection and report. Replaying the same fixture and external evaluation values reproduces all domain events, IDs, genealogy, frontier membership, explainability projections, report text, and checkpoint state.
